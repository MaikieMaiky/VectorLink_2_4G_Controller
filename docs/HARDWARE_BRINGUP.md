# 上板检查清单

## 上电前

- 检查 3.3 V、VBAT、VBUS 和地之间无明显短路。
- 确认 NRF CE 默认低、CSN 默认高。
- 确认 SWD 可连接且 PB3/PB4 未恢复为 JTAG。

## 基础运行

- 烧录后确认启动蜂鸣器两段短鸣。
- 调试器观察 Input、Radio、UI 三个任务均在运行。
- 记录三个任务的 `uxTaskGetStackHighWaterMark()`，低于 64 words 时增大栈。
- 检查 FreeRTOS heap 剩余量和 map 文件 RAM 使用。

## ADC、摇杆和电池

- 确认 DMA 顺序为 LH、LV、RH、RV、BAT。
- 记录四轴中心、最小、最大值，更新 `app_config.hpp`。
- 检查四轴正负方向，按需要修改 `kJoystickReversed`。
- 使用万用表对比 VBAT 与软件显示电压，修正 VDDA 或分压误差。
- 分别验证 3.5 V 低电和 3.3 V 严重低电告警。

## 按键

- 逐个检查 K1..K12 位图与丝印功能。
- 检查按下、长按和释放不会产生重复边沿。
- 确认 K9 可以切换 OLED 页面并触发短鸣。

## OLED

- 扫描或确认地址为 `0x3C`。
- 检查方向、对比度、全屏刷新和长期刷新稳定性。
- OLED 缺失时确认输入和无线任务仍正常运行。

## NRF24L01 与 AT2401C

- 读取 RF_CH 等寄存器确认 SPI 通信。
- 用另一块 NRF24L01 验证控制包、自动 ACK 和 ACK Payload。
- 检查 IRQ 下降沿只唤醒 Radio 任务，不在 ISR 中执行 SPI。
- 验证 MAX_RT、断开接收端、恢复接收端和 500 ms 失联逻辑。
- 近距离测试通过后再逐步增加距离，观察 AT2401C 电源和发射稳定性。

## 蜂鸣器

- 检查启动、切页、低电、无线失败和失联提示。
- 根据实物谐振效果调整各模式频率和占空比。

## 最终记录

- 将实测校准值和方向提交到 Git。
- 记录 OLED 型号/地址、NRF 模块版本、电池类型和测试距离。
- 只有完成双端通信和失联保护测试后，才将固件标记为硬件验证版本。
