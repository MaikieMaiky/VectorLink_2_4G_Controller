# 开发进度与验证记录

## 已实现

- C++17 应用入口和三任务 FreeRTOS 结构。
- ADC1 五通道循环 DMA 与稳定快照读取。
- 四轴摇杆整数滤波、死区、方向和 `-1000..1000` 映射。
- 12 按键三次稳定采样消抖及边沿检测。
- 单节锂电池电压、百分比和低电等级计算。
- TIM4 非阻塞蜂鸣器提示模式。
- SSD1306/SSD1315 兼容 I2C OLED 驱动及两页状态界面。
- NRF24L01 硬件 SPI、IRQ、自动应答、动态载荷和 ACK Payload。
- 24 字节控制/遥测协议和最近 32 包链路质量统计。
- CMake/CTest 主机逻辑测试。

## 当前验证

- Arm Compiler 6、C++17、LTO：全量编译和链接通过。
- 主机测试：摇杆、按键、电池、协议 CRC、遥测解码和链路统计通过。
- 格式检查：自有 C/C++ 文件符合仓库 `.clang-format`。
- 当前链接尺寸：Flash 26.5 KiB / 64 KiB，静态 RAM 14.6 KiB / 20 KiB。

没有硬件时，以上结论只证明代码和纯逻辑一致，不能替代电气和时序实测。

## 已知限制

- 摇杆中心、端点和方向使用默认值，尚未实测校准。
- 电池百分比使用 3.3 V 到 4.2 V 的线性估算，不代表真实放电曲线。
- OLED 地址暂定 `0x3C`，SSD1315 的兼容性尚未上板确认。
- NRF 地址和频道是开发默认值，V1 尚未实现配对或持久化设置。
- 遥测的四个数值保持通用定义，需由未来接收端赋予具体含义。
- USART 日志尚未接入，首轮上板调试可按需要增加。
